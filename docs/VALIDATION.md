## 本地发布检查

检查 manifest、内容脚本与样式、图标、静态资源引用和 JavaScript 语法：

```sh
node tools/validate-release.cjs dafeiyu-cleaner
```

生成可直接在 Chromium 中“加载已解压的扩展程序”的快照：

```sh
node tools/validate-release.cjs dafeiyu-cleaner --snapshot
```

快照位于仓库根目录 `release/chromium-<version>-<UTC时间>-<随机后缀>/`，包含 `BUILD-INFO.json` 和每个源文件的 SHA-256。检查与快照只证明本地文件闭合、可解析，不代替浏览器兼容性或页面矩阵验收。工具会拒绝把输出写进扩展源目录。

## 已完成的真实页面烟测

在 Edge 156 中重新加载当前工作区的扩展后，使用全新页面完成了以下检查：

- 抖音视频页读取到 17 个评论节点，其中 16 个出现扩展标记；页面出现“证据不足”“隐藏”“保留账号”等扩展控件。

- B 站普通视频页滚动到评论区域后完成懒加载，快照中出现 14 个“证据不足”扩展标记，以及“隐藏”“保留账号”和回复内容。

抖音页面自带的“内容由AI生成”属于平台内容，不计作扩展输出。上述结果是有限样本的安装烟测，不代表所有评论都已标记，也不代表识别准确率。
