# 抖音桌面网页版接入

实现日期：2026-11-05。本阶段交付评论采集和本地处理，AI 准确性专项后置。

## 使用方法

1. 在 chrome://extensions 或 edge://extensions 重新加载本地 `dafeiyu-cleaner` 扩展。
2. 刷新已经打开的抖音标签页，进入视频并打开评论面板。manifest 新增的匹配范围需要刷新页面才能生效。
3. 已加载的评论和回复使用抖音独立证据策略；资料不足时显示“证据不足”。点击“隐藏”会隐藏该账号在本页的已加载评论并加入抖音独立名单。
4. 评论区上方点击“显示”可撤销本次隐藏；以后再遇到名单账号会显示折叠入口，也可在扩展名单页移除。“保留账号”加入白名单，优先于隐藏名单。

仅处理网页已加载内容，不主动批量抓取全部评论。隐藏顶层评论时，其内的回复线程也会一起隐藏；恢复后线程重新显示。

## 范围与能力

- 匹配 https://www.douyin.com/* 和 https://douyin.com/*，不匹配直播子域或移动短链。
- 作品上下文支持 URL `modal_id`、`/video/<id>` 和推荐流当前视频的 DOM ID；URL 与当前挂载视频不一致时等待新评论区。
- 支持已加载评论、楼中楼、表情替代文本、明确带主页链接的提及、平台独立账号名单。
- 缺少账号 ID 时仅允许当前会话评论操作；缺少稳定评论 ID 时跳过，未知结构显示受限状态。
- 不运行 B 站识别规则，不调用抖音平台 API 或模型接口，不注入 MAIN 脚本或拦截网络请求。
- 抖音使用独立的保守证据策略：明确的自动发送/运营自述才会成为强候选，昵称、作者徽标、AI 作品标签和普通短回复不会单独确认账号。抖音未开放主页鉴定、头像颜色分析和评论动画；设置页的 DeepSeek 配置仍只用于 B 站，自动处理默认关闭。

## 真实 DOM 证据

在登录可访问的抖音精选视频弹层及直接视频页检查了以下结构，不依赖散列 CSS 类名：

| 字段 | 读取位置 |
| --- | --- |
| 当前作品 | URL `modal_id`、`/video/<id>`；`[data-e2e="feed-active-video"]` 的 data-e2e-vid |
| 评论区 | 当前视频内 `[data-e2e="comment-list"]` |
| 评论/回复 | `[data-e2e="comment-item"]`；嵌套关系区分楼中楼 |
| 本条头部 | 属于当前评论的 `.comment-item-info-wrap`，排除子回复头部 |
| 评论 ID | 头部 `[data-e2e="video-comment-more"] [id^="tooltip_"]` 的数字后缀，保持字符串 |
| 账号 ID | 头部 `/user/<secUID>` 主页链接，secUID 作为不透明字符串 |
| 正文 | 本条头部之后的正文元素，跳过插件标签；递归保留文本、换行和图片 alt |
| 回复关系 | 最近外层评论的 ID 作为 rootId；无法确定具体被回复者时 parentId 为 null |

结构中的 tooltip ID 与头部后的正文位置仍属于网页内部约定，抖音改版后可能变化。没有推断相对时间的绝对时间戳、等级或认证信息；这些字段保持缺失。

## 实现与验证

`src/platforms/douyin/shared.js` 提供 URL、DOM 字段、能力和挂载规则；`adapter.js` 提供监听、标准批次和绑定生命周期。MutationObserver 合并变更，1 秒补扫处理节点替换和同路径视频变化。插件自身插入的 UI 不触发采集反馈循环。

绑定关联 sessionId、评论键、账号链接和根节点；失效后移除注入节点、取消动画、恢复仍由插件拥有的样式。隐藏撤销按原评论键清除状态，避免恢复承载新评论的复用节点。

用户已在 Edge 中重新加载本地扩展并刷新 B 站、抖音。新建直接视频页读取 17 条评论并出现 16 个扩展标记；手动隐藏后出现“已隐藏 1 条”和“显示”，恢复及展开回复后无残留状态。站点原生“内容由AI生成”标签不算插件结果。自动化回归及后续待验收清单见 [改造进度](MULTI_PLATFORM_PROGRESS.md)。
