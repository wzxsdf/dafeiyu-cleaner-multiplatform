# 第一版使用说明

本目录为 Chromium 解压扩展。第一版目标为 Edge / Chrome 的 B 站普通视频评论区、抖音网页版直接视频评论区。当前已完成本地收口，正式交付前还需要第二轮真实浏览器验收。

## 安装与更新

1. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本文件所在目录（同级有 `manifest.json`）。目录需要长期保留。
3. 安装或重新加载后，刷新已打开的 B 站、抖音页面，关闭并重新打开设置面板。
4. 更新已有扩展时，在原目录替换文件再点“重新加载”。不要先卸载；卸载会清除本地数据，必要时先导出名单。

## 使用

- B 站打开普通视频并滚到评论区；抖音打开 `https://www.douyin.com/video/<作品ID>` 并打开评论面板。插件只读取页面已经加载的评论和回复。
- “证据不足”表示当前资料无法判断，不表示没有工作；昵称、AI 话题和平台“AI 生成”标签不能确认自动运营。
- 点击“隐藏”处理当前账号的已加载评论，并加入该平台本地名单；点击通知中的“放回来”或评论区上方的“显示”恢复。名单账号以后可能显示折叠条，也可在名单页移除。
- 点击“保留账号”加入该平台白名单，优先于隐藏名单；这只是你的展示选择，不代表已验证真人身份。
- 点击工具栏扩展图标调整开关、极简模式或管理名单。设置按字段自动保存，看到“设置已保存到本机”后再关闭面板。保存失败会显示提示，不要将失败当成已生效。
- 名单页带平台标识，可导出/导入 JSON；B 站与抖音相同昵称或 ID 不会共用名单。

## 第一版边界

默认只标记，按识别结果自动隐藏和按提及隐藏暂不开放。手动隐藏名单会继续生效。抖音不调用模型，不提供主页鉴定或评论动画；不需要 API Key 即可使用核心流程。B 站模型复核为额外可选能力。

Firefox、手机 App、其他平台、复杂推荐流，以及分 P/番剧/主页的完整页面矩阵均不在本次交付范围。识别准确率尚未用真实标注集校准，普通短回复可能始终显示“证据不足”。全部隐藏操作仅影响本机显示，不会删除、举报或拉黑账号。
