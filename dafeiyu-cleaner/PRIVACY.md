# 隐私说明 · 大肥鱼消除计划

更新日期：2026-11-05

## 我们收集什么

什么都不收集。插件没有自己的服务器，也不包含任何统计或埋点。

## 插件在你的电脑上保存什么

以下数据只保存在你浏览器的 `chrome.storage.local` 中，卸载插件即删除：

- 设置项（处理方式、严格度、音效开关等）
- DeepSeek API Key（如果你填写了）
- 遣返名单 / 人类白名单（平台标识、账号 ID、昵称、头像地址、时间；抖音使用主页链接中的 secUID）
- 战绩统计
- 识别结果缓存：仅用于当前页面的渲染与请求去重，不把账号识别结果作为跨页面前科加分
- DeepSeek 精判结果缓存：B 站账号 ID、启发式复核分和一句证据说明，保存 7 天，分数不是校准概率
- 你上传的自定义形象图片

抖音适配仅从已加载评论 DOM 读取作品 ID、评论 ID、账号链接、昵称、正文、表情及提及，在本页内处理；手动名单保存在本地，不发送抖音评论给模型服务。不读取抖音 Cookie、令牌或私有接口。名单页可加载已保存的头像地址。

## 插件会访问哪些网络地址

| 地址 | 用途 | 时机 |
| --- | --- | --- |
| `api.bilibili.com` | 读取公开的用户资料卡与投稿列表，用于空间主页鉴定 | 打开某个空间主页时 |
| `i0/i1/i2.hdslb.com` | B 站主页报告按用户选择读取公开头像地址 | 打开主页报告并启用模型复核时 |
| `api.deepseek.com` | DeepSeek 精判 | 仅当你开启精判并填写了自己的 API Key |

当前 DeepSeek 精判仅支持 B 站。开启后，发送给 DeepSeek 的内容仅限于：账号昵称、可用等级、签名、最多 8 条评论及回复关系、当前页面和离线证据；主页报告另含近期投稿标题，头像仅在你启用主页模型复核且模型支持时发送。抖音评论不会发送给模型。这些内容会受 DeepSeek 自身的隐私政策约束。在 Firefox 中，打开精判开关时浏览器会询问你是否允许发送网页内容，不同意则只使用离线规则。

## 插件不会做什么

- 不读取、不发送你的 Cookie 或登录信息
- 不以你的身份发评论、点赞、举报、拉黑或删除任何内容
- 「赶走」「折叠」「泡泡大炮」都只是修改你本地看到的页面
- 名单导出是在你本机生成 JSON 文件，不会上传到任何地方
